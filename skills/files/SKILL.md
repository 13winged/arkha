# Файлы

Работа с файлами в папках, которые пользователь разрешил. Вне разрешённых
папок инструмент не вызывается — объясни, что папка не разрешена, и спроси
разрешение.

## Обязательные правила

1. **Перед записью — показать путь.** Пользователь подтверждает папку.
2. **Перед удалением — показать точный путь.** Не `«файл из загрузок»`,
   а полный путь.
3. **Удаление — в корзину, не мимо неё.** Оригинал должен быть
   восстановим.
4. **Readback после записи.** Создал файл → открыл → сверил содержимое.
   Сообщение «файл создан» не доказательство.
5. **Перезапись существующего файла — только после подтверждения.**
   Переименование и перемещение — не перезапись, но путь всё равно
   показывай.

## Когда данных не хватает

Обязательное поле нечем заполнить → остановиться и спросить. Не выдумывать
имя файла, не подставлять заглушку, не создавать пустой документ вместо
содержимого.

## Когда результат не найден

Сказать «не нашёл» и показать, где искал. Не пересказывать содержимое
похожего файла.
