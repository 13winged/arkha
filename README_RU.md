# ArkHa 1.2

ArkHa — локальный ИИ-секретарь для Windows. Модели запускаются через `llama.cpp`, данные остаются на компьютере, а доступ к файлам, окнам, памяти, голосу и навыкам контролируется разрешениями.

## Что нового в 1.0

- Единый киберпанк-интерфейс для главного окна, RAG и окна агента.
- Статичная правая панель модели: состояние, GPU, запуск/остановка и голос.
- Чат секретаря с сохраняемой историей и видимым журналом инструментов.
- RAG-корпус для локального поиска по документам.
- Режимы агента: «План», «Рассуждение» и «Сборка».
- Ограниченный доступ к выбранным папкам, чтение текста и открытие файлов штатными приложениями Windows.
- Скрытые консольные окна `llama-server.exe`, `nvidia-smi` и голосовых сервисов.
- Очистка осиротевших процессов WebView2 и production CSP.
- Русский и английский интерфейс, сохранение размера шрифта.

## Возможности 1.2

- Runtime Manager для CPU/CUDA/Vulkan с проверкой совместимости и SHA-256.
- Локальная библиотека моделей с группировкой по семействам и квантовкам.
- Реестр навыков: включение, выключение, permissions и просмотр `SKILL.md`.
- Context Builder агента с локальным RAG, профилем пользователя и ограниченной историей tool calls.
- Локальные вложения: metadata в SQLite, файлы в `%APPDATA%\\ArkHa\\attachments`.
- Текстовые вложения автоматически индексируются в локальный RAG.

## Требования

- Windows 10 1809 или новее.
- Node.js 20+.
- Rust stable MSVC и Visual Studio C++ Build Tools.
- WebView2 Evergreen Runtime.
- Совместимые `llama-server.exe` и GGUF-модель. Они не хранятся в репозитории.

## Разработка

```powershell
npm install
npm run app:dev
```

## Сборка

```powershell
npm run app:build
```

Исполняемый файл появится в `target/release/arkha.exe`, а установщики — в `target/release/bundle/`.

## Проверка

```powershell
npm run check
npm run test:rust
npm run check:i18n
```

Сейчас проходят 333 Rust-теста; ещё 3 аппаратных теста помечены `ignored`.

## Безопасность

Доступ к файлам ограничен выбранными папками. Запись, запуск программ и управление окнами регулируются режимом агента и подтверждениями. Управление интерфейсом выполняется через accessibility references, без кликов по координатам.
