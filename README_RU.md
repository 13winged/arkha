# ArkHa 1.3

ArkHa — локальный ИИ-секретарь для Windows. Модели запускаются через `llama.cpp`, данные остаются на компьютере, а доступ к файлам, окнам, памяти, голосу, документам и навыкам контролируется разрешениями.

## Что нового в 1.3

- **Документы**: `docs.read`, `docs.info` и `docs.write` читают и создают docx, pdf, xlsx и pptx через закреплённые CLI ArtCraft по MCP. Каждый архив и исполняемый файл проверяются по SHA-256; GridCraft ArkHa открывает сам и не показывает модели инструменты с путями.
- **Отдельная загрузка**: CLI документов ставятся из «Настройки» → «Документы» с полосой прогресса. Инструменты сами ничего не качают, поэтому отсутствующий CLI даёт понятный отказ, а не молчаливое ожидание на несколько минут.
- **Интерфейс в духе ArtCraft**: прямоугольные поверхности, плоские панели, сгруппированный сайдбар, статус под моделью, память квадратами.
- **Своё меню**: пункты переставляются перетаскиванием или стрелками, лишние скрываются, «Сбросить порядок» возвращает сгруппированный вид.
- **Наблюдение**: кольцо бюджета токенов на всю ширину панели, живые карточки CPU/ОЗУ/VRAM и график за две минуты, а также тест скорости модели в правом докбаре.
- **Навыки OpenCode**: навыки из `%USERPROFILE%\.agents\skills` видны во вкладке «Навыки»; внешние выключены, пока их не включат по одному.
- **Уровни глитча**: выкл, мягкий, обычный, жёсткий. Обычный и жёсткий остаются горизонтальными, жёсткий добавляет вертикальные полосы.

## Возможности 1.2

- Runtime Manager для CPU/CUDA/Vulkan с проверкой совместимости и SHA-256.
- Локальная библиотека моделей с группировкой по семействам и квантовкам.
- Реестр навыков: включение, выключение, permissions и просмотр `SKILL.md`.
- Context Builder агента с локальным RAG, профилем пользователя и ограниченной историей tool calls.
- Локальные вложения: metadata в SQLite, файлы в `%APPDATA%\ArkHa\attachments`.
- Текстовые вложения автоматически индексируются в локальный RAG.

## Возможности 1.0

- Единый киберпанк-интерфейс для главного окна, RAG и окна агента.
- Статичная правая панель модели: состояние, GPU, запуск/остановка и голос.
- Чат секретаря с сохраняемой историей и видимым журналом инструментов.
- RAG-корпус для локального поиска по документам.
- Режимы агента: «План», «Рассуждение» и «Сборка».
- Ограниченный доступ к выбранным папкам, чтение текста и открытие файлов штатными приложениями Windows.
- Скрытые консольные окна `llama-server.exe`, `nvidia-smi` и голосовых сервисов.
- Очистка осиротевших процессов WebView2 и production CSP.
- Русский и английский интерфейс, сохранение размера шрифта.

## Требования

- Windows 10 1809 или новее.
- Node.js 20+.
- Rust stable MSVC и Visual Studio C++ Build Tools.
- WebView2 Evergreen Runtime.
- Совместимые `llama-server.exe` и GGUF-модель. Они не хранятся в репозитории.
- Поддержка документов необязательна: CLI ArtCraft скачиваются по требованию из их подписанных релизов на GitHub.

## Безопасность

Доступ к файлам ограничен выбранными папками. Запись, запуск программ и управление окнами регулируются режимом агента и подтверждениями. Управление интерфейсом выполняется через accessibility references, без кликов по координатам.

Инструменты документов подчиняются тем же правилам: путь проверяется до запуска CLI, CLI получает только папку самого файла как корень чтения или записи, а версия и оба SHA-256 сверяются с закреплёнными. Собственный MCP-сервер GridCraft не умеет ограничивать папки, поэтому книгу открывает ArkHa, а инструменты с аргументом-путём модели не показываются.
