**ArkHa** — локальный ИИ-секретарь для Windows. Работает целиком на вашей машине: голос, доступ к файлам и окнам, документы, память. Без облака, без телеметрии, без учётной записи.

Приложение на Tauri 2 вокруг `llama.cpp`. Модель выбирается сама, под ваше железо: на 8 ГБ ОЗУ и RTX 3060 будет одна, на 64 ГБ и RTX 4090 — другая.

> [!IMPORTANT]
> ArkHa умеет читать ваши файлы, управлять окнами и запускать программы. По умолчанию он работает в режиме **«только показывать»** и спрашивает перед чем-то опасным, но это всё равно программа с настоящими правами. Прочитайте [На что он способен](#на-что-он-способен), прежде чем выдавать доступ.

## Возможности

- **Честный реестр возможностей** — у каждой из 18 способностей указан гейт, которым она проверена, и точный отказ, который она даст, когда не может. Непроверенные помечены как непроверенные, а не тихо выданы за работающие.
- **Модель выбирается сама** — приложение определяет процессор, ОЗУ и видеопамять, подбирает профиль от T1 до T5 и поднимает модель, которая влезет. Настраивать руками ничего не нужно.
- **Уровни доступа, у которых есть смысл** — по умолчанию только показывать, выполнение по желанию, и выбор, когда спрашивать: опасные действия, всё подряд или ничего.
- **Голос, который вы включаете сами** — распознавание Qwen3-ASR, синтез Qwen3-TTS, через тот же `llama-server`. Сам не поднимается.
- **Управление окнами без координат** — агент находит элементы через UI Automation и нажимает их **по видимой подписи**. Клик по пикселям не реализован и не будет реализован.
- **Доступ к файлам по папкам** — отметьте отдельные папки или выдайте весь диск, причём это явное отдельное решение, а не папка `C:\` в списке, которая молча значит «всё».
- **Встроенный подбор моделей** — наберите `gemma`, и вернётся всё семейство со счётчиками скачиваний. Фильтр только по GGUF, чтобы всё найденное можно было скачать и запустить.
- **Полоса памяти, которая не врёт** — ОЗУ и видеопамять читаются живьём. Если видеопамять измерить не удалось, она прячется, а не угадывается.
- **Оформление по образцу игрового инвентаря** — плоско, волосяные линии, срезанные углы, и цвет только там, где что-то значит.
- **2 языка интерфейса** — русский и английский, переключаются одной кнопкой и запоминаются между запусками.

## Быстрый старт

Скачайте установщик из [релизов](https://github.com/13winged/arkha/releases) и запустите. Потом нажмите **«Загрузка»** и возьмите модель — приложение подскажет ту, что влезет в ваш профиль.

Сборка из исходников:

```bash
git clone https://github.com/13winged/arkha
cd arkha
npm install
npx tauri build --release
```

Бинарники `llama.cpp` в репозитории не лежат — это сотни мегабайт на каждый чип. Приложение ищет их рядом с собой и в `data/bin`.

Тесты: `cargo test --manifest-path src-tauri/Cargo.toml` (256 штук) · Гейты идут по живому железу и запускаются отдельно, см. [Проверка](#проверка).

## На что он способен

Три уровня, и каждый говорит прямо, чего стоит.

| Уровень | Что происходит |
|---|---|
| **Только показывать** (`dry-run`) | Секретарь пишет, что собирается сделать, и ждёт. Без вашего слова ничего не происходит |
| **Опасные — спросить** (`actions`, по умолчанию) | Согласные действия выполняются сразу; удаление, запуск программ и перезапись файлов требуют подтверждения |
| **Не спрашивать** (`never`) | Делает всё, что разрешено. Промах в команде он не остановит |

Доступ к файлам — решение отдельное от выполнения: либо отдельные папки, либо весь диск, и на экране написано именно то, что вы разрешили. «Весь диск» не подставляется как `C:\` в списке папок.

## Поддерживаемое железо

**Минимум:** Windows 10 1809 или новее, 8 ГБ ОЗУ. Видеокарта не обязательна.

**Профиль подбирается автоматически:**

| Профиль | Нужно | Обычная модель |
|---|---|---|
| **T1** | 8 ГБ ОЗУ, без GPU | Qwen3.5 4B, контекст 16K |
| **T2** | 16 ГБ ОЗУ | Qwen3.5 9B, контекст 32K |
| **T3** | 32 ГБ + 8 ГБ VRAM | Qwen3.5 9B, контекст 64K |
| **T4** | 32 ГБ + 12 ГБ VRAM | Qwen3.5 27B, контекст 128K |
| **T5** | 32 ГБ + 24 ГБ VRAM | Qwen3.5 27B, контекст 256K |

Таблица выше — это план. Что получит ваша машина, измерено на машине разработки (Ryzen 7 8700F, 32 ГБ, RTX 5060 8 ГБ): **профиль T3, Qwen3.5 9B Q5_K_M, все 33 слоя на GPU, контекст 64K**. Все числа в `docs/10-замеры.md` взяты оттуда и больше ниоткуда.

## Голос

| Часть | Модель | Замер |
|---|---|---|
| Распознавание | `Qwen3-ASR-0.6B-Q8_0` | **274 мс** на фразу, **143 МиБ** в ОЗУ |
| Синтез | `Qwen3-TTS-1.7B-Q4_K_M` | **3.87×** реального времени, Apache-2.0 |

Распознавание намеренно идёт **на процессоре**. На карте оно занимает 2594 МиБ и отвечает за 86 мс; в оперативке — 143 МиБ и 274 мс. Вернуть 2.4 ГиБ стоит 188 мс, особенно когда модель уже заняла всю карту.

Обе модели `Apache-2.0`, проверено через API Hugging Face 14.10.2026. Репозитории со сборками GGUF своей лицензии не объявляют; подробности в [docs/09-лицензии.md](docs/09-лицензии.md).

## Проверка

Обычные тесты быстрые и идут где угодно:

```bash
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

Гейты проверяют живую машину — настоящую модель, настоящее окно Chrome, настоящий файл на диске. Только там утверждение «работает» что-то значит:

| Гейт | Что доказывает |
|---|---|
| `s3_gate` | целостность реестра возможностей |
| `s4_gate` | знакомство верно собирает настройки |
| `s6_gate` | чтение файлов и навыки |
| `s8_gate` | чтение окон, запуск и управление на живом рабочем столе |
| `uia_gate` | дерево UI Automation и нажатие по кнопке в настоящем Chrome |
| `vision_gate` | чтение изображений отдельной моделью |
