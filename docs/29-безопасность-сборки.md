## Блокер для Authenticode-подписи

Нужен доверенный Windows code-signing certificate (PFX или сервис cloud signing). Закрытый ключ и пароль нельзя коммитить или отправлять в чат — хранить только в GitHub Actions Secrets/Environment. Без сертификата можно публиковать SHA-256 и provenance, но это не подтверждает издателя и не убирает предупреждения SmartScreen.

Рекомендуемые секреты workflow:

- `WINDOWS_CERTIFICATE` — base64-содержимое PFX либо credential для выбранного signing service;
- `WINDOWS_CERTIFICATE_PASSWORD` — пароль PFX, если используется PFX;
- timestamp URL доверенного RFC 3161 timestamp-сервера.

Подписывать и проверять как минимум основной exe, поставляемые exe/dll движка и оба установщика. Выпускать подпись с SHA-256 и timestamp; после подписи проверять все файлы через `signtool verify /pa /all /v`.
