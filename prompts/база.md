Вставляется в каждую сессию. Копировать полностью.

---

## Проект

ArkHa — локальный ИИ-секретарь для Windows. Голос, доступ к ПК,
документы, память.

Своё приложение. ODS, Hermes и AIRI — референсы, не зависимости.

Рабочая директория: `arkha/`

---

## Что делает продукт

Пользователь узнаёт, что умеет агент, и собирает его в разговоре.
Дальше — голос, интернет, документы, управление ПК. Всё локально.

Первый и главный сценарий — **знакомство**. Он определяет успех продукта.

## Технические решения

| Вопрос | Ответ |
|---|---|
| Оболочка | Tauri 2 + React + TypeScript + Vite |
| Рантайм | нативный процесс, **без WSL2 и Docker** |
| Инференс | `llama-server.exe` сайдкаром, OpenAI-совместимый HTTP |
| Модель | Qwen3.5, по профилю: 4B → 9B → 27B |
| Агентный рантайм | свой код |
| Управление ПК | UIA-first, `browser_dom_*` отдельно, vision на T4+ |
| Хранилище | sqlite-vec для документов, SQLite + FTS5 для истории |
| Навыки | формат agentskills.io |
| Установка | один `.exe`, без терминала и перезагрузок |

**Почему без Docker:** +2–4 ГБ RAM на Docker и WSL2, перезагрузка при
установке, COM и UIA из WSL не работают. На 16 ГБ RAM это разница между
«впритык» и «свободно».

**Почему сайдкар, а не библиотека:** падение инференса не должно ронять
UI. Обновляется отдельно.

## Аудитория

Неоднородный парк машин. Пять профилей, определяются автоматически
по VRAM и RAM.

| Профиль | RAM | VRAM | Модель | Контекст |
|---|---|---|---|---|
| T1 | 8 ГБ | встройка / 4 ГБ | Qwen3.5 4B Q4 | 16K |
| T2 | 16 ГБ | 8 ГБ | Qwen3.5 9B Q4_K_M | 32K |
| T3 | 32 ГБ | 8 ГБ | Qwen3.5 9B Q5_K_M | 64K |
| T4 | 32 ГБ | 12–16 ГБ | Qwen3.5 27B Q4_K_M | 128K |
| T5 | 64 ГБ+ | 24 ГБ+ | Qwen3.5 27B Q4_K_M | 262K |

**Проверка на T1 и T2 встроена в каждый этап.** Функция, работающая
на T3 и падающая на T1, недоступна половине пользователей.

## Приватность

По умолчанию: всё локально, синхронизация выключено, облако выключено,
телеметрии нет. Пользователь включает всё сам.

Индикатор показывает, когда запрос ушёл в облако.

---

## Правило адаптации

**Функция либо работает полностью, либо не показывается вовсе.**

Половина функции хуже, чем её отсутствие: пользователь не поймёт,
что сломалось. На T1 нет RAG — кнопка не появляется, с объяснением
«недоступно на вашем железе: {причина}».

## Стиль работы

**MVP-first.** Kevin с Хабра — 100 строк, даёт полный доступ к ПК.
Если цикл не работает на 100 строках, он не заработает на 10 тысячах.

**Один этап — одна сессия.** Не тянуть два.

**Гейт обязателен.** Не пройден — этап не закончен.

**Типизированные аргументы.** Модель никогда не передаёт сырые команды.

**Инварианты из `prompts/правила.md`** соблюдаются всегда, без исключений.
Читай этот файл перед каждым этапом.

**Не начинать с кода, которого не просили.** Если этап требует только
профиля — не строить модель-менеджер.
